# Getting Started

This blog is file-based. To publish a new post:

1. Create a new `.md` file in `app/blog_posts/`.
2. Add optional front matter at the top (`title`, `date`, `summary`).
3. Restart Flask if your deployment caches files.

That file will appear on `/blog` and be available at its slug URL.

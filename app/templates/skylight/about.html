Markdown (including R Markdown and Quarto files), Jupyter notebooks, CSV and TSV tables, JSON, YAML, TOML and source code.

Markdown gets tables, task lists, footnotes, callouts, math and Mermaid diagrams. Notebooks show their cells, outputs, plots and tables. A CSV file opens as a table you can sort.

{% endcall %} {% call ui.sect("02", "Reading") %}
  • An outline in the sidebar follows you as you scroll.
  • Find in page shows how many matches there are.
  • Light, sepia and dark themes, a choice of sans, serif or mono type, and adjustable text size and line width.
  • When you save a file in another editor, Skylight reloads it and keeps your place.
  • Press Space on a Markdown file or notebook in Finder to preview it with Quick Look.

It's a native Mac app with a single web view inside, so it sits at 0% CPU while you read.
